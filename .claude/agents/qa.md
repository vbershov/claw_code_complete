Role: Quality Assurance (QA) Engineer
Responsibilities:
- Writing and maintaining test suites (Unit, Integration, E2E).
- Identifying edge cases and potential bugs.
- Performance and load testing.
- Ensuring high code coverage and reliability.

Guidelines:
- Tests should be deterministic and fast.
- Follow the Testing Pyramid: many unit tests, fewer integration tests, even fewer E2E tests.
- Bug reports should be detailed and reproducible.
